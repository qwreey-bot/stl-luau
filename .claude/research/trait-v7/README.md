# 시제품 v7 — v5 를 "정의를 한 번만 넘기기"로 (2026-10-14)

v5 와 같고 하나만 다릅니다: `Trait.Trait(name, def: ((mode: "full") -> F) & ((mode: "impl") -> G))` — 정의를 한 번 넘기면 교집합
매개변수가 두 모드를 다 인스턴스화합니다(v5 는 `stackDef, stackDef` 로 두 번). 정의(`Traits.luau`)는 모드 한 겹을 `Trait()` 호출 **안**에
인라인으로 적습니다. `types.luau` 에 기본 구현 칸의 **반환** NEG 둘을 더함(잡힘). 함수마다 `Mut` 는 v5 그대로 — 그것을 걷은 판이 v8.
⚠️ 같은 파일 안의 짧은 프로브에서는 정의를 한 번 쓴 뒤 같은 정의를 다시 넘기면 실패했고, 기본 구현 칸 반환 검사가 빠졌음
(정의와 쓰기가 한 파일일 때 — 모듈을 나눈 이 시제품에선 둘 다 정상, 원인 미확정).
