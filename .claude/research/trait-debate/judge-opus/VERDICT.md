## 3. 들일 때의 조건과 안전장치

### 3-1. 음성 대조군 배터리(`spikes` + `spike-expectations.tsv`)에 고정할 것

- **(a) 같은 모듈에서 기본 구현의 반환 NEG**(`types.luau` 의 `NEG_sameRet` 꼴)
  - 기본 구현이 있는 트레이트마다 하나씩 둡니다.
  - 정의 모듈 안에서 그 트레이트를 쓰게 되므로, `never` 폴스루의 경보 역할을 합니다.
  - "맞바꿈" 실수는 정의 줄이 아니라 첫 쓰기 줄에서 터집니다(`definer-mistakes` 27행). 그래서 이 NEG 가 맞바꿈도 함께 덮습니다.
- **(b) 다른 모듈에서의 반환 NEG**(`NEG_ret1/2`)
- **(c) 재정의 서명 NEG**(`Fold = Len`, `U` 를 못박은 것)
- **(d) 정의자 실수 스파이크**: 맞바꿈, 글자, 안 부름, IMPL 빠뜨림, 하나만 넘김. 전부 "에러가 나야 함" 으로 고정합니다(`definer-mistakes` + `j2`·`j7`).
- **(e) 성장 POS**: 필수만 적은 등록이 기본 구현을 더한 뒤에도 0건인지(`j1b` 꼴).
- **(f) 경계 줄을 0건으로 고정**: 등록 표의 남는 칸(오타), 리터럴 직접 등록(`j4`), 토큰으로 밝힌 `T`. 동작이 바뀌면 알아채려는 용도입니다.

### 3-2. 규약 문장(conventions)

- 기본 구현이 있는 트레이트는 `Trait.Trait(이름, def(Trait.FULL), def(Trait.IMPL))` 로 정의합니다.
  `<<"full">>` 나 한 번 넘기기는 **쓰지 않습니다.** 기본 구현 칸은 `Default(mode, 빌더)` 입니다.
- **모든 트레이트가 `XImpl` 별칭을 내보냅니다**(기본 구현이 0개여도).
- 등록은 `XImpl<…>` 주석을 단 지역 변수에 적고 `X.ImplFor(토큰, 지역)` 으로 넘깁니다.
  - **리터럴을 바로 넘기면 타입이 하나도 검사되지 않습니다**(`j4`: 서명이 틀리고 칸이 빠져도 0건 — 모든 후보 공통, `ImplFor` 의 `impl: any`).
  - `check.sh` 의 파일 단위 검사에 `ImplFor(…, {` 패턴을 막는 덫을 하나 두는 것을 권합니다. 값이 싸고, "실수를 잡는 덫" 경계와도 맞습니다.
- 기본 구현의 타입에 오버로드(`&`)를 쓰지 않습니다. 레드팀 구멍 2(`(A & B)?` 에 한쪽 갈래만 든 함수가 0건)는 선택 칸을 쓰는 모든 후보에 공통입니다. 지금 `src` 의 `Provided` 도 마찬가지입니다.
- 명시적 타입 인자는 다 줍니다. 덜 주면 나머지가 `unknown` 이 됩니다(레드팀 구멍 4, 모든 후보 공통).
- 재정의 이름의 오타는 런타임 등록 줄 에러와 `spec.contracts` 배선 전수가 책임집니다. 타입의 한계로 문서에 적습니다.

### 3-3. 모든 후보 공통의 후퇴: 진입점이 `any`

`List.IndexOf(d, x)` 가 `any` 가 되는 것은 지금 `src` 의 손으로 쓴 진입점보다 후퇴입니다. 비용 0 으로 되찾는 길이 있습니다(`j6`).

- 트레이트 모듈에서 진입점에 타입만 캐스트합니다: `const Push: <S, T>(stack: S & Item<T>, item: T) -> S = Stack.Push :: any`.
- 그러면 `Push(d, "x")`, 빌린 참조로 쓰기, 반환 타입이 잡힙니다.
- 캐스트가 정의와 어긋나는지(표류)는 탐침 타입으로 대입하는 줄 하나가 잡습니다(`j6` 24행).
- 경계: `IndexOf(d, "z")` 는 0건입니다. conventions 의 "`==` 비교만 하는 값은 넓어져도 됨" 과 같은 동작입니다.

라이브러리의 트레이트 일곱에 이걸 할지는 사용자가 정할 선택지입니다.

### 3-4. 들일 때 확인할 것

- 시제품은 작습니다. `src` 규모(트레이트 일곱, 컨테이너 열)로 옮긴 뒤 TypeError 총계와 배터리를 다시 확인합니다.
- luau-lsp 에서도 같은 결과가 나오는지 봅니다. CLI 는 `Luau*` 플래그를 다 켜지만 다른 도구는 다를 수 있습니다(`luau-source` 1-3).

## 4. 남는 위험

1. **`index<>` 축약은 상류 동작에 기댑니다.** 바뀌면 실패가 조용합니다(`never`). 3-1(a) 가 그것을 잡는 유일한 그물입니다.
2. **정의자 실수의 문구가 거칩니다.** `Property 'string' does not exist on type '{ full: …, impl: … }'` 가 열 줄 넘게 퍼지고, 쓰는 자리까지 번집니다(`j3b`·`j7`). 시끄럽지만 읽기 어렵습니다. 템플릿과 `Trait` 머리 주석으로 메웁니다.
3. **리터럴 직접 등록은 검사 0건입니다**(`j4`). 덫(3-2)이 없으면 열려 있습니다.
4. **공통으로 남는 것**: 오버로드 기본 구현의 부분 재정의, 타입 인자를 덜 준 경우, 남는 칸 오타, 뭉텅이 몸통은 탐침 타입으로만 검사됨.
